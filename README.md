# NexusFlow

NexusFlow is a visual IoT telemetry and rule engine that allows users to build
data-processing pipelines through a visual node-based interface.

## Tech Stack

### Frontend
- React
- Vite
- React Flow
- React Router
- Axios
- Recharts

### Backend
- Node.js
- Express
- Mongoose
- MongoDB Atlas
- Nodemon
